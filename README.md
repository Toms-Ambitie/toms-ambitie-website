# toms-ambitie.nl

Website van Toms Ambitie, venture club uit Zwolle.

- Ontwerpregels, bron en werkafspraken: [ONTWERP.md](ONTWERP.md)
- Ontwikkelen: `npm install`, dan `npm run dev`
- Bouwen: `npm run build` (maakt ook de sitemap en per pagina de Google-gegevens)
- Hosting: Vercel. `main` is productie; werk op `redesign-2026`.
